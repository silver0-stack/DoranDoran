# 도란도란 - 가족 소통 안드로이드 애플리케이션

## 활동 내역서

본 프로젝트는 가족 구성원 간의 원활한 소통을 지원하는 안드로이드 모바일 애플리케이션 '도란도란' 개발에 참여하였습니다. Kotlin 언어를 주력으로(96.2%) 사용하여 개발되었으며, Firebase 실시간 데이터베이스, Material Design Components, ViewBinding 등 최신 안드로이드 기술 스택을 활용하였습니다. 주요 기여 내역은 다음과 같습니다: (1) 사용자 인증 모듈 구현(SignInActivity, SignUpActivity, PasswordAppActivity 등 account 패키지), (2) 프로필 관리 기능 개발(profile/start, profile/edit 모듈), (3) 가족 캘린더 기능 구현(calendar 패키지 - MainCalendarActivity, ScheduleWritingActivity, MentionBottomsheet 등), (4) 우편함 기능 개발(mailbox 패키지 - 받은편지함/보낸편지함/편지작성), (5) 실시간 채팅 기능 구현(ChatActivity, ChatAdapter), (6) 온보딩 화면 및 메인 화면 UI 개발(OnBoardingActivity, MainActivity), (7) Firebase Realtime Database 연동 및 Firebase Storage를 활용한 이미지 업로드, (8) RecyclerView 기반 리스트 어댑터 구현(MainScheduleAdapter, MainfamilyAdapter 등), (9) 단위 테스트 및 통합 테스트 작성(ExampleUnitTest.kt, ExampleInstrumentedTest.kt). GitHub 협업 활동으로는 코드 커밋 [commit-hash], Pull Request 생성 및 리뷰 [PR#], 이슈 트리아지, README 문서화 작업에 기여하였습니다. 팀 내 역할은 UI/UX 설계 30%, 기능 구현 50%, 테스트 및 디버깅 20%로 구성되었으며, Android Jetpack 컴포넌트 활용 및 Firebase 백엔드 통합을 담당하였습니다.
